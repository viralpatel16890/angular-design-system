# Component API Reference

This is the authoritative, per-component API reference for `angular-ds`, generated by reading each component's actual `.ts`/`.html`/`.scss` source. It exists to close a documentation gap: the Showcase app is a visual demo, not an API reference, and about half the library previously had no documented public API outside its source code.

**Scope note:** this document covers every component in `projects/angular-ds/src/lib/components/` as of the latest merge — **31 component directories**, listed below. (Confirm Dialog, Empty State, Menu, Pagination, Skeleton, and Spinner were added after the initial pass and appended in a follow-up update rather than a full alphabetical re-sort — see their entries below. Stat Card replaces the former Balance Card and Metric Card, appended the same way. Radio Group was added afterward too, but slotted alphabetically since it lands between two already-sorted entries.) All are standalone Angular components using the signals-first `input()` / `output()` API and `ChangeDetectionStrategy.OnPush` unless noted otherwise. Every component is importable from the root package (`import { ... } from 'angular-ds'`) or its named sub-path (`import { ... } from 'angular-ds/<name>'`).

For the global design-token system (primitive/semantic/component tiers, dark mode, theming), see the root [README](../README.md#token-system). This document only calls out CSS custom properties that a *specific* component reads directly (beyond the global token system) and that a consumer could reasonably override at the component level.

## Accordion

`ds-accordion` / `AccordionComponent`

Collapsible content sections built on a CSS grid expand/collapse animation, supporting single- or multi-expand mode.

**Inputs**

| Name | Type | Default | Description |
|---|---|---|---|
| `items` | `AccordionItem[]` | *required* | The list of sections to render. `AccordionItem = { id, title, content, disabled?, expanded? }`. `expanded` on an item only seeds initial state (read once in `ngOnInit`). |
| `multiple` | `boolean` | `false` | Allow more than one section to be expanded at once. |
| `bordered` | `boolean` | `true` | Draws a border/divider around and between sections. |

**Outputs**

| Name | Emits | Description |
|---|---|---|
| `itemToggle` | `{ id: string; expanded: boolean }` | Fires whenever a section is expanded or collapsed. |

**CSS custom properties**

| Property | Default | Notes |
|---|---|---|
| `--accordion-bg` | `var(--color-surface-base)` | Section background. |
| `--accordion-border` | `var(--color-border-default)` | Outer/divider border color. |
| `--accordion-radius` | `var(--radius-md)` | Corner radius when `bordered`. |
| `--accordion-text` / `--accordion-text-muted` | `var(--color-text-primary)` / `var(--color-text-secondary)` | Trigger and content text colors. |
| `--accordion-hover-bg` | `var(--color-surface-subtle)` | Trigger hover background. |

**Usage**

```html
<ds-accordion
  [items]="[
    { id: 'a', title: 'What is this?', content: 'An accordion section.' },
    { id: 'b', title: 'Second item', content: 'More content here.', disabled: false }
  ]"
  [multiple]="false"
  (itemToggle)="onToggle($event)"
/>
```

## Alert

`ds-alert` / `AlertComponent`

Dismissible inline alert banner with `info` / `success` / `warning` / `danger` variants, each with its own icon.

**Inputs**

| Name | Type | Default | Description |
|---|---|---|---|
| `variant` | `'info' \| 'success' \| 'warning' \| 'danger'` | `'info'` | Controls color and icon (ℹ / ✓ / ⚠ / ✕). |
| `title` | `string` | `''` | Optional bold heading line. |
| `message` | `string` | `''` | Body text of the alert. |
| `dismissible` | `boolean` | `true` | Shows a close button that hides the alert. |

**Outputs**

| Name | Emits | Description |
|---|---|---|
| `dismissed` | `void` | Fires once, when the user dismisses the alert (sets internal `visible` signal to `false`). |

**CSS custom properties**

| Property | Notes |
|---|---|
| `--alert-bg`, `--alert-border`, `--alert-fg` | Set per-variant (e.g. `info` → `var(--color-info-subtle)` / `var(--color-info-default)` / `var(--color-info-default)`); override to recolor a specific alert instance. |

**Usage**

```html
<ds-alert
  variant="warning"
  title="Heads up"
  message="Your session will expire in 5 minutes."
  (dismissed)="onAlertDismissed()"
/>
```

## Avatar

`ds-avatar` / `AvatarComponent`

User avatar that shows an image, falls back to initials derived from `name`, then falls back to a generic icon. Supports an optional status dot.

**Inputs**

| Name | Type | Default | Description |
|---|---|---|---|
| `src` | `string` | `''` | Image URL. Falls back to initials/icon if empty or if the image fails to load. |
| `alt` | `string` | `''` | Alt text for the image. |
| `name` | `string` | `''` | Used to derive initials (first + last word initials, or first two characters). |
| `size` | `'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl'` | `'md'` | Avatar diameter. |
| `shape` | `'circle' \| 'square'` | `'circle'` | Avatar shape. |
| `status` | `'online' \| 'offline' \| 'away' \| 'busy' \| null` | `null` | Renders a status dot when set. |
| `color` | `string` | `''` | Optional color key applied as `ds-avatar--color-{value}` for the initials background. |

**Outputs**

None.

**CSS custom properties**

None beyond the global token system — this component does not define its own component-level custom properties.

**Usage**

```html
<ds-avatar name="Ada Lovelace" size="lg" status="online" />
<ds-avatar src="https://example.com/user.jpg" alt="Jane Doe" shape="square" />
```

## Button

`ds-button` / `ButtonComponent`

Themed action button with multiple variants, sizes, and a built-in loading state.

**Inputs**

| Name | Type | Default | Description |
|---|---|---|---|
| `variant` | `'primary' \| 'secondary' \| 'danger' \| 'ghost' \| 'link'` | `'primary'` | Visual style. |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | Button size. |
| `type` | `'button' \| 'submit' \| 'reset'` | `'button'` | Native `type` attribute. |
| `disabled` | `boolean` | `false` | Disables the button (also true while `loading`). |
| `loading` | `boolean` | `false` | Shows a loading state and blocks clicks. |
| `fullWidth` | `boolean` | `false` | Stretches the button to 100% width. |
| `ariaLabel` | `string \| null` | `null` | Optional `aria-label` override, e.g. for icon-only buttons. |

**Outputs**

| Name | Emits | Description |
|---|---|---|
| `pressed` | `MouseEvent` | Fires on click, only when the button is not disabled/loading. |

**CSS custom properties**

| Property | Notes |
|---|---|
| `--btn-bg`, `--btn-bg-hover`, `--btn-bg-active`, `--btn-text`, `--btn-border`, `--btn-border-hover` | Set per-variant; override for a one-off recolor. |
| `--btn-radius`, `--btn-font-size`, `--btn-font-weight`, `--btn-padding-x`, `--btn-padding-y`, `--btn-gap` | Sizing/shape tokens, mostly driven from global tokens but overridable per instance. |

**Usage**

```html
<ds-button variant="primary" size="md" [loading]="isSaving" (pressed)="save()">
  Save changes
</ds-button>
```

## Card

`ds-card` / `CardComponent`

Layout container. Composes with `ds-card-header`, `ds-card-body`, and `ds-card-footer` (each documented separately below).

**Inputs**

| Name | Type | Default | Description |
|---|---|---|---|
| `variant` | `'elevated' \| 'outlined' \| 'filled'` | `'elevated'` | Visual treatment (shadow, border, or filled background). |
| `padding` | `'none' \| 'sm' \| 'md' \| 'lg'` | `'md'` | Outer padding preset (`ds-card--p-{value}`). |
| `interactive` | `boolean` | `false` | Adds hover/active affordance for clickable cards. |
| `fullHeight` | `boolean` | `false` | Stretches the card to fill its container's height. |

**Outputs**

None.

**CSS custom properties**

| Property | Default | Notes |
|---|---|---|
| `--card-bg` | `var(--color-surface-base)` | Card background (changes to `var(--color-surface-subtle)` for the `filled` variant). |
| `--card-border` | `var(--color-border-default)` | Border color (`outlined`/default variants). |
| `--card-radius` | `var(--radius-xl)` | Corner radius. |
| `--card-shadow` | `var(--elevation-2)` | Drop shadow (`none` for `outlined`/`filled`). |
| `--card-padding` | `var(--space-6)` | Also read by `ds-card-header`, `ds-card-body`, and `ds-card-footer` as their padding fallback — override once on `ds-card` to change padding consistently across all card slots. |

**Usage**

```html
<ds-card variant="elevated" padding="md">
  <ds-card-header>
    <span slot="title">Account Summary</span>
  </ds-card-header>
  <ds-card-body>Your balance is up 4.2% this month.</ds-card-body>
  <ds-card-footer justify="end">
    <ds-button variant="ghost" size="sm">Dismiss</ds-button>
  </ds-card-footer>
</ds-card>
```

## Card Header

`ds-card-header` / `CardHeaderComponent`

Title/subtitle/action slot for the top of a card. Content projection, not a `title` input — project title text into the `[slot=title]` slot.

**Inputs**

| Name | Type | Default | Description |
|---|---|---|---|
| `subtitle` | `string` | `''` | Optional subtitle line rendered under the projected title. |

**Outputs**

None.

**Content slots:** `[slot=title]` (heading content), `[slot=action]` (trailing action, e.g. a button or menu), plus a default slot for any extra content under the title.

**CSS custom properties**

Reads `--card-padding` (see [Card](#card)) as its padding fallback; no custom properties of its own.

**Usage**

```html
<ds-card-header subtitle="Last updated 2 minutes ago">
  <span slot="title">Portfolio</span>
  <ds-button slot="action" variant="ghost" size="sm">Refresh</ds-button>
</ds-card-header>
```

|---|---|---|---|

## Checkbox

`ds-checkbox` / `CheckboxComponent`

Accessible checkbox with indeterminate state and native `ControlValueAccessor` support (works with `ngModel` and reactive forms). Renders a `ds-form-error` automatically from a bound `NgControl`'s validation errors.

**Inputs**

| Name | Type | Default | Description |
|---|---|---|---|
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | Checkbox size. |
| `label` | `string` | `''` | Label text. |
| `labelPosition` | `'right' \| 'left'` | `'right'` | Label placement relative to the box. |
| `helperText` | `string` | `''` | Helper text shown below the control when there is no validation error. |
| `disabled` | `boolean` | `false` | Disables the control. |
| `required` | `boolean` | `false` | Marks the control as required (affects the default "required" error message). |
| `indeterminate` | `boolean` | `false` | Sets the native `indeterminate` DOM property (applied in `ngAfterViewInit`). |
| `checked` (alias for `defaultChecked`) | `boolean` | `false` | Initial checked state (read once in `ngOnInit`); for two-way/reactive-forms binding use `ngModel`/`formControl` instead. |

**Outputs**

| Name | Emits | Description |
|---|---|---|
| `checkedChange` | `boolean` | Fires on every native `change` event with the new checked state. |

**CSS custom properties**

| Property | Default | Notes |
|---|---|---|
| `--cb-size` | `1.125rem` | Box dimensions. |
| `--cb-border` | `var(--color-border-strong)` | Unchecked border color. |
| `--cb-bg` | `var(--color-surface-base)` | Unchecked background. |
| `--cb-checked-bg` / `--cb-checked-border` | `var(--color-brand-primary)` | Checked-state fill/border. |
| `--cb-mark` | `var(--color-on-interactive)` | Checkmark color. |

**Usage**

```html
<ds-checkbox
  label="I agree to the terms"
  [(ngModel)]="agreed"
  (checkedChange)="onAgreeChange($event)"
/>
```

## Crypto Ticker

`ds-crypto-ticker` / `CryptoTickerComponent`

Live-style price ticker row for a crypto asset. Once `price` is non-zero, the component internally simulates small price fluctuations on an interval (own `effect`/`setInterval`, cleaned up via `DestroyRef`) and flashes briefly on each update — this is a self-contained visual effect, not driven by real market data.

**Inputs**

| Name | Type | Default | Description |
|---|---|---|---|
| `symbol` | `string` | `'BTC'` | Ticker symbol shown next to the name. |
| `name` | `string` | `'Bitcoin'` | Full asset name. |
| `price` | `number` | `0` | Starting price (seeds the internal simulated price; `0` disables the simulation). |
| `change24h` | `number` | `0` | 24h percent change; sign drives the up/down indicator (`absChange` is the displayed magnitude). |
| `logo` | `string` | `'₿'` | Emoji/character used as the asset's logo glyph. |

**Outputs**

None.

**CSS custom properties**

None beyond the global token system.

**Usage**

```html
<ds-crypto-ticker symbol="ETH" name="Ethereum" [price]="3182.44" [change24h]="-1.8" logo="Ξ" />
```

**Inputs**

**Outputs**

**Usage**

## Input

`ds-input` / `InputComponent`

Text field with label, helper/error text, and native `ControlValueAccessor` support. Automatically derives an error message from a bound `NgControl`'s validators (`required`, `email`, `minlength`, `maxlength`, `pattern`) unless `errorMessage` is set explicitly.

**Inputs**

| Name | Type | Default | Description |
|---|---|---|---|
| `type` | `'text' \| 'email' \| 'password' \| 'number' \| 'tel' \| 'url' \| 'search' \| 'date'` | `'text'` | Native input type. |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | Field size. |
| `status` | `'default' \| 'error' \| 'success' \| 'warning'` | `'default'` | Visual status; `'error'` forces the error state even without a bound control. |
| `label` | `string` | `''` | Field label. |
| `placeholder` | `string` | `''` | Placeholder text. |
| `helperText` | `string` | `''` | Helper text shown below the field when there is no error. |
| `errorMessage` | `string` | `''` | Explicit error text; overrides the auto-derived validator message. |
| `disabled` | `boolean` | `false` | Disables the field. |
| `required` | `boolean` | `false` | Marks the field as required. |
| `readonly` | `boolean` | `false` | Makes the field read-only. |
| `name` | `string` | `''` | Native `name` attribute. |
| `autocomplete` | `string` | `'off'` | Native `autocomplete` attribute. |

**Outputs**

| Name | Emits | Description |
|---|---|---|
| `valueChange` | `string` | Fires on every native `input` event with the current value. |

**CSS custom properties**

| Property | Default | Notes |
|---|---|---|
| `--input-bg`, `--input-text`, `--input-placeholder` | `var(--color-surface-base)` / `var(--color-text-primary)` / `var(--color-text-tertiary)` | Field colors. |
| `--input-border`, `--input-border-hover`, `--input-border-focus` | Default/hover/focus border color; swapped per `status` (error/success/warning). |
| `--input-radius`, `--input-font-size`, `--input-padding-x`, `--input-padding-y`, `--input-height` | Sizing tokens. |

**Usage**

```html
<ds-input
  label="Email"
  type="email"
  placeholder="you@example.com"
  [(ngModel)]="email"
  (valueChange)="onEmailChange($event)"
/>
```

## Modal

`ds-modal` / `ModalComponent`

Accessible dialog built on the native `<dialog>` element, with Angular CDK focus trapping, Escape-to-close, and optional backdrop-click-to-close.

**Inputs**

| Name | Type | Default | Description |
|---|---|---|---|
| `open` | `boolean` | `false` | Controls whether the dialog is shown (`showModal()`/`close()` are called reactively via `ngOnChanges`). |
| `size` | `'sm' \| 'md' \| 'lg' \| 'xl' \| 'full'` | `'md'` | Dialog width preset. |
| `title` | `string` | `''` | Header title; also drives `aria-labelledby`. |
| `closeOnBackdrop` | `boolean` | `true` | Clicking outside the dialog panel closes it. |
| `closeOnEscape` | `boolean` | `true` | Pressing Escape closes it. |
| `hideClose` | `boolean` | `false` | Hides the header close (×) button. |

**Outputs**

| Name | Emits | Description |
|---|---|---|
| `closed` | `void` | Fires whenever the modal is closed (via close button, backdrop click, or Escape) — the consumer is expected to flip `open` to `false` in response. |

**Content slots:** default slot (body content), `[slot=footer]` / `ds-modal-footer` (optional footer content).

**CSS custom properties**

| Property | Default | Notes |
|---|---|---|
| `--modal-width` | `32rem` | Dialog panel width (collapses to `100%` on small/mobile breakpoints). |
| `--modal-radius` | `var(--radius-xl)` | Corner radius. |
| `--modal-bg` | `var(--color-surface-overlay)` | Panel background. |
| `--modal-shadow` | `var(--elevation-5)` | Drop shadow. |
| `--modal-padding` | `var(--space-6)` | Internal padding. |

**Usage**

```html
<ds-modal [open]="isOpen" title="Confirm action" (closed)="isOpen = false">
  <p>Are you sure you want to continue?</p>
  <div slot="footer">
    <ds-button variant="ghost" (pressed)="isOpen = false">Cancel</ds-button>
    <ds-button variant="primary" (pressed)="confirm()">Confirm</ds-button>
  </div>
</ds-modal>
```

## Navbar

`ds-navbar` / `NavbarComponent`

Top navigation bar with links, per-item badges, active-item styling, and a built-in mobile hamburger menu. Brand and actions are content-projected, not input-driven.

**Inputs**

| Name | Type | Default | Description |
|---|---|---|---|
| `items` | `NavItem[]` | `[]` | Nav links: `{ label, href?, active?, disabled?, badge? }`. |
| `sticky` | `boolean` | `true` | Sticks the navbar to the top of the viewport. |
| `bordered` | `boolean` | `true` | Draws a bottom border. |

**Outputs**

| Name | Emits | Description |
|---|---|---|
| `itemClick` | `NavItem` | Fires when a nav link (desktop or mobile) is clicked; also closes the mobile menu. |
| `menuToggled` | `boolean` | Fires when the mobile hamburger menu opens/closes, with the new open state. |

**Content slots:** `[slot=brand]`, `[slot=actions]` (desktop), `[slot=mobile-actions]` (shown inside the open mobile menu).

**CSS custom properties**

| Property | Default | Notes |
|---|---|---|
| `--navbar-height` | `3.5rem` | Bar height. |
| `--navbar-bg` / `--navbar-border` | `var(--color-surface-base)` / `var(--color-border-default)` | Background and border. |
| `--navbar-link-text`, `--navbar-link-hover`, `--navbar-link-active` | Link color states. |
| `--navbar-px` | `var(--space-6)` | Horizontal padding. |

**Usage**

```html
<ds-navbar
  [items]="[{ label: 'Dashboard', href: '/', active: true }, { label: 'Reports', href: '/reports' }]"
  (itemClick)="onNavClick($event)"
>
  <span slot="brand">Acme</span>
  <ds-button slot="actions" variant="primary" size="sm">Sign out</ds-button>
</ds-navbar>
```

## Progress

`ds-progress` / `ProgressComponent`

Progress bar with semantic color variants, three sizes, optional stripe/animation, and an ARIA `progressbar` role.

**Inputs**

| Name | Type | Default | Description |

## Radio Group

| `label` | `string` | `'Metric'` | Card heading text. |
| `value` | `number` | `0` | Raw numeric value; formatted per `compact`/`decimals`. |
| `trend` | `number \| undefined` | `undefined` | Percentage change. Omitted entirely hides the trend indicator (e.g. a plain count with nothing to compare against); pass a number, including `0`, to show the ▲/▼ indicator. |
| `compact` | `boolean` | `false` | When `true`, abbreviates `value` with K/M suffixes above 1,000/1,000,000 (former metric-card behavior). When `false`, formats with thousands separators and `decimals` fraction digits (former balance-card behavior). |
| `decimals` | `number` | `2` | Fraction digits used in non-compact (decimal) formatting. |
| `prefix` | `string` | `''` | Text prepended to the formatted value, e.g. `'$'` for currency. |
| `suffix` | `string` | `''` | Text appended to the formatted value, e.g. a unit. |
| `icon` | `string` | `'📊'` | Emoji/character shown in the card header. |
| `accent` | `'neutral' \| 'cyan' \| 'violet' \| 'amber'` | `'neutral'` | Accent color for the value and trend styling. `'neutral'` keeps the value in the library's default primary text color. |
| `caption` | `string` | `''` | Optional caption shown next to the trend indicator, e.g. `'vs last month'`. |

**Outputs**

None.

**CSS custom properties**

| Property | Default | Notes |
|---|---|---|
| `--stat-accent` | `var(--color-text-primary)` | Overridden per `accent` value; drives the big value's color. |

**Usage**

```html
<!-- Currency amount (former ds-balance-card) -->
<ds-stat-card
  label="Trading Account"
  [value]="48213.92"
  prefix="$"
  [trend]="2.4"
  accent="violet"
  caption="vs last week"
/>

<!-- Compact count (former ds-metric-card) -->
<ds-stat-card label="Active Users" [value]="128400" [trend]="3.2" [compact]="true" />
```
